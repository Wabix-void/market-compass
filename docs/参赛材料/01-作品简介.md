## 版本 A：长版（约 600 字，适合无严格字数限制或限 800 字以内）

**作品名称**：商情罗盘 · MarketCompass

**一句话定位**：面向中小电商卖家的公开商情洞察与 AI 选品参谋。

中小卖家选品长期依赖经验与手工比价：数据散落在各平台，看得到销量却看不清竞争结构，拿得到表格却得不到结论。本作品把公开渠道的商品销量代理信号、价格、榜单与评价信息汇聚为结构化指标，再用「指标层 + 大模型 + 证据链校验」输出可执行的选品、定价与竞争策略建议。

**系统已完整跑通三类数据源**：① 公开页面采集（苏宁易购搜索页，两轮采集共 80 个真实商品入库）；② 官方开放平台适配器（淘宝/京东/拼多多，含签名、限速、配额与「粘贴即用」的凭据配置向导）；③ 演示数据集（4 大类 15 个细分类目、356 个条目、19,936 条日指标）。

**两项核心设计**：

1. **销量代理指标（SPS）**：公开数据拿不到平台真实销量（京东搜索页只返回 2.7KB 空壳、价格由 JS 异步加载、淘宝与唯品会的 robots.txt 明确禁止抓取搜索页）。系统用「公开已售增量 + 评价增量反推 + 榜单分位反推」三路信号融合，输出**置信区间**与四种明确口径，拒绝把估算包装成真值。

2. **证据链强制校验**：AI 输出的每条结论都绑定「指标名 + 数值 + 周期 + 来源 + 置信度」，生成后回指标层**逐条重算比对**（相对容差 0.5%），任一条无法复现即整体降级为「数据不足」。这是从架构上抑制幻觉，而非依赖提示词。

用户在「商品行情分析」页输入任意商品名（如「保温杯」），系统自动解析标的、罗列行情数据（规模、趋势、价格带、品牌份额、竞争集中度、评价痛点、增长榜），并给出带证据链的判断与建议；未覆盖的商品明确返回「数据未覆盖」并给出候选标的，不编造行情。

**合规章节**：只采集公开可访问数据，遵守 robots.txt、限速 3 秒/请求、不采集任何个人信息、不绕过登录与风控；每次采集写入审计台账，可逐条追溯数据来源。

**工程完整性**：零第三方依赖（纯 Python 标准库实现），两条命令即可本地复现全流程，附 35 项端到端冒烟测试与 18 项适配器单元测试。

## 版本 B：短版（约 220 字，适合 200–300 字限制）

商情罗盘 MarketCompass 是面向中小电商卖家的公开商情洞察与 AI 选品参谋。

系统采集公开渠道的商品销量代理信号、价格、榜单与评价，构建结构化指标，再用「指标层 + 大模型 + 证据链校验」输出选品、定价与竞争策略建议。用户输入任意商品名即可获得行情罗列与带证据的判断。

两项核心设计：**销量代理指标（SPS）** 用三路公开信号融合并输出置信区间，诚实面对"公开数据拿不到真实销量"；**证据链强制校验** 要求 AI 每条结论都能回指标层重算复现，否则整体降级为"数据不足"。

已跑通苏宁公开页真实数据采集（80 个商品）与淘宝/京东/拼多多官方 API 适配器；零第三方依赖，两条命令即可复现；全程遵守 robots、限速且不采集个人信息。
