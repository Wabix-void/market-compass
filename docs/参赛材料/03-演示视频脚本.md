# 演示视频脚本（3 分钟版）

> 你需要自己录屏（我无法代录）。下面按时间轴给了**操作步骤 + 台词**，照着做即可。
> 建议用 Windows 自带 `Win + G`（Xbox Game Bar）或 OBS 录制，分辨率 1920×1080。

## 录制前准备（3 分钟）

```bash
cd E:\dsh-workspace\market-compass
python scripts/bootstrap.py            # 准备演示数据
python scripts/run_server.py           # 启动服务，保持窗口开着
```

浏览器打开 http://127.0.0.1:8787 ，按 `F11` 全屏。

**注意**：
- 录制前把窗口调成 1920×1080，浏览器缩放设 100%，否则字太小
- **不要录制 `config/openapi.env`**（如果有），不要展示任何密钥
- 录制时鼠标动作放慢，别抖
